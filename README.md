# よみまる支援ハブ

## 概要

「よみまる支援ハブ」は、新聞配達を行いながら学業に取り組む学生向けの支援Webアプリケーションです。

学習と仕事の両立をサポートするため、学校情報管理、メモ機能、カレンダー、天気情報、地図機能、アカウント管理などを一つのシステムに統合しました。

---

## 主な機能

* Firebase Authentication によるユーザー認証
* メールアドレス・パスワードによる新規登録
* ログイン・ログアウト機能
* ログイン状態の保持
* 学校情報管理
* メモ機能
* カレンダー機能
* 天気情報表示
* 地図機能
* アカウント管理
